01 / Handbook

MUMRO Academy

An open, growing collection of practical guides on brand systems, multi-format content, technical SEO, AI agents and MCP.

Where it came from

System-building notes turned into an open handbook

While building Mumro and running Świadek Dziejów across several channels, I kept running into the same problems: how to keep tone and facts consistent without pasting the same instructions into every chat, how to turn one researched topic into native formats for different platforms without mechanical copy-paste, and how to give AI agents tool access without risking accidental live publications.

Instead of leaving those notes scattered across private docs, I organised them into the four tracks of MUMRO Academy. It records the architectural trade-offs, YAML/JSON schemas and small interactive labs behind the systems — written so you can apply them in your own workflow.

01CLI · NODE.JS · MIT · CODEX / CLAUDE CODE / ANTIGRAVITY / CURSOR

Agent Harness Kit

Design, generate and check a coding agent’s working environment for new or existing repositories.

View repository ↗

When you ask an agent to write AGENTS.md from scratch, it often guesses scripts that don't exist, adds generic rules nobody asked for, and drifts as soon as the repository changes. Agent Harness Kit builds the harness from evidence in your repo and explicit decisions.

  • Scan & Design: reads real commands from project manifests and detects sensitive areas (such as database migrations, payments or auth), then asks only what it cannot infer, saving your answers to .harness/spec.json.
  • Explain: prints the reason and context cost for every included section and every part left out — and clearly separates advisory instructions from real enforcement.
  • Build & Check: generates AGENTS.md, a CLAUDE.md entry point and skills (SKILL.md) without overwriting hand-written notes, and verifies consistency with check as the project evolves.
Quick start in a repository 
npx github:RolePlayingTech/agent-harness-kit design
npx github:RolePlayingTech/agent-harness-kit explain
npx github:RolePlayingTech/agent-harness-kit build --dry-run
npx github:RolePlayingTech/agent-harness-kit check

02CLI · NODE.JS · MIT · MODEL CONTEXT PROTOCOL / SKILL.MD

MCP Surface Kit

Declaratively describe and validate MCP tool interfaces, permissions, safe operations and related agent skills.

View repository ↗

MCP Surface Kit is not an MCP server or runtime SDK. It is a design and validation tool that checks the declared contract you expose to an agent (.mcp-surface/spec.json) before the agent is allowed to call tools against live data. Static contract validation does not replace server-side security enforcement — authentication, scope checks and Prepare → Confirm tokens still have to be enforced by the backend runtime and verified with integration tests.

  • Four explicit tool tiers: requires tools to be classified as read, draft, mutate or delete with matching MCP safety annotations (readOnlyHint, destructiveHint, openWorldHint).
  • Prepare → Confirm gates: requires every live mutation tool to form a reciprocal prepare and confirm pair, and enforces explicit safety guards on delete operations.
  • Scopes & conflict-safe SKILL.md generation: validates scope hierarchies (scopes, operationScopes), flags untrusted returned fields, and generates SKILL.md files with SHA-256 ownership markers and --dry-run diffs.
Validate and build skills 
npx github:RolePlayingTech/mcp-surface-kit explain
npx github:RolePlayingTech/mcp-surface-kit check --strict
npx github:RolePlayingTech/mcp-surface-kit build --dry-run
npx github:RolePlayingTech/mcp-surface-kit build
