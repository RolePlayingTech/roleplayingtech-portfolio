# RolePlayingTech — kierunek strony v2

Ta wersja zastępuje pierwotne propozycje wizualne w briefie v1.0.

- Osobiste portfolio, nie agencyjny szablon.
- Kolorystyka: ciepłe, papierowe tło; atrament, szarości, przygaszona oliwka. Bez granatowo-cyjanowych gradientów.
- Układ przypomina osobisty dziennik projektowy: odważna typografia, duże niesymetryczne prezentacje projektów, krótkie autorskie teksty.
- Projekty: Mumro, Świadek Dziejów, Crewly, MFC. Nie wymyślać case studies, klientów ani rezultatów.
- Projektowe wizualizacje CSS są tymczasowe i **nie przedstawiają rzeczywistych screenshotów**. Docelowo wstawić autentyczne materiały dostarczone przez właściciela.
- PL i EN utrzymane w osobnych katalogach.
- Nowe teksty celowo są mniej korporacyjne, bardziej osobiste; zmiany to propozycja do iteracji.
- Repo publiczne — dokumenty w docs/ są publicznie czytelne; nie dodawać tajnych informacji.
