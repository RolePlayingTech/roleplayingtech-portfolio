# RolePlayingTech — strona osobista, nie landing page

## Kierunek (15 października 2026)

Użytkownik chce minimalistycznej, wyrazistej strony pokazującej realną pracę i doświadczenie, która może przyciągać klientów, ale nie będzie brzmieć jak reklama ani odgrywać agencji.

- **Najpierw praca** — cztery konkretne projekty jako prosty indeks z czytelnymi stronami szczegółów.
- **Bez udawania** — żadnych sztucznych statystyk, opinii, nazw klientów ani fikcyjnych screenshotów.
- **Mniej znaczy więcej** — dominacja typografii, jasne tło, ciemny tekst, niewielki ciepły akcent, bez gradientów i ilustracji pozorujących produkty.
- **Prawdziwe obrazy** — wykorzystane już istniejące w repozytorium zdjęcia camp.jpg i mfc.jpg; nazwy i opisy projektów nie udają mockupów.
- **Współpraca, nie sprzedaż** — zaproszenie do zwyczajnej rozmowy zamiast hasła 'innowacyjnych usług'.
- **Doświadczenie** — pełniejsza historia i zakres kompetencji na oddzielnej podstronie O mnie.
- **PL/EN** — niezależne naturalnie sformułowane wersje językowe każdej podstrony.
- **Bez zewnętrznego JS** — statyczny serwis w GitHub Pages; ścieżki katalogów i linki działają bez routera.

Plik jest zapisem decyzji projektowej, nie narzuca w przyszłości tej konkretnej estetyki. Dokumenty strategii i pierwotny brief pozostają w repozytorium.
